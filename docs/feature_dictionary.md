# Arcora NBA Game Feature Dictionary

This dictionary documents all **242** pregame input features, **8** metadata columns, and **5** target columns in `data/features/nba_game_features.parquet`.

## 1. Identifier & Metadata Columns

| Column | Dtype | Role | Description |
| :--- | :--- | :--- | :--- |
| `game_id` | `int64` | Primary Key | Unique NBA game identifier. |
| `game_date` | `datetime64[ns]` | Metadata | Calendar date of game (EST). |
| `season` | `int64` | Metadata | NBA season start year (`2003`–`2022`). |
| `season_label` | `string` | Metadata | Formatted season string (`2003-04`–`2022-23`). |
| `game_type` | `string` | Metadata | Competition stage (`Regular Season`, `Playoffs`, `Play-In`). |
| `is_partial_season` | `bool` | Metadata | True for the partial `2022-23` season (`season == 2022`). |
| `home_team_id` | `int64` | Foreign Key | Home team franchise ID (`teams.team_id`). |
| `away_team_id` | `int64` | Foreign Key | Away team franchise ID (`teams.team_id`). |

## 2. Prediction Target Columns (Excluded from Input Matrix `X`)

| Target Column | Task Type | Dtype | Formula | Description |
| :--- | :--- | :--- | :--- | :--- |
| `home_pts` | `regression` | `int64` | `games.home_pts` | Final points scored by the home team. |
| `away_pts` | `regression` | `int64` | `games.away_pts` | Final points scored by the away team. |
| `point_margin` | `regression` | `int64` | `home_pts - away_pts` | Final signed point differential from the home team perspective. |
| `total_pts` | `regression` | `int64` | `home_pts + away_pts` | Combined final points scored by both teams. |
| `home_win` | `binary_classification` | `bool` | `home_pts > away_pts` | Binary outcome indicator (True if home team wins). |
